## Session Notes

### Patterns established / reinforced

- **Generalize root-cause fixes when a per-route patch becomes whack-a-mole.** The B11 scroll fix started as inline useLayoutEffect on ListingView. The Pass-1 technical evaluator flagged this as a global-stylesheet root cause that would silently recur on any new intra-site mid-page CTA. Refactoring to a shared hook applied to all six ecommerce route entries closes the recurrence path AND documents the constraint in globals.css for future contributors.
- **Schema extensions need parallel updates in three known sites.** This session's analogue: catalog-derived prose. "Six SKUs" in the demos-section was hardcoded; a future SKU add would silently leave it stale. The fix derives the cardinal from `products.length` at render time + cross-pins the test against the catalog length. Same pattern as the WebVital schema-columns/sGTM-trigger sequencing from session-2026-04-25-009.
- **Negative regression pins matter for copy rewrites.** Pass-1 product reviewer flagged the workshop tier copy as substantially improved. The implementation pinned both directions: `expect(/causation, not correlation/i)` AND `expect(text).not.toMatch(/finally answering/i)`. Without the negative pin, a future polish pass could regress to the old subtitle and only fail if the assertion happened to be on the OLD text — usually it's only on the NEW text. Both directions = both regressions caught.
- **Evaluator-driven Pass-1 fix-pack cadence.** The product reviewer found a Major (sub-nav inconsistency the user didn't explicitly call out) + the technical evaluator found 4 Importants. Closing both pre-PR converged the work without a second user round-trip. Pattern: spawn dual evaluators in parallel, address findings while waiting, verify with Pass-2.

### Architecture decisions

- **`useScrollToTopOnMount` as a shared hook, not a per-route useLayoutEffect.** The hook's documentation acknowledges the back-nav scroll-restoration tradeoff. Applied broadly so the fix follows the user across the demo subtree, not just on the listing.
- **Sub-nav simplification on B12.** Two options were considered: replace the chiweenie wordplay with a functional tagline ("the tuna shop · shop") or drop it entirely. Drop won — the wordmark stands on its own; the right-side `shop · cart` wayfinding provides functional navigation; the layout doesn't need a vestigial second-line tag.
- **B17 spacing harmonization scoped to bio only.** Product reviewer flagged the bio's `pt-section + pb-8 md:pb-12` asymmetry. The fix dropped mobile top to `pt-12` (48px) for closer-to-symmetric mobile while keeping desktop's `pt-section` for editorial weight. The "What I believe" + closer sections were left alone — three different spacing regimes IS a smell, but harmonizing all three risks over-reaching beyond the user's specific UAT r3 ask.
