## Issues & Technical Debt

**Three code commits are un-reviewed** — see Review Results.

**One pattern, three instances, and it is the finding of the session.** A
committed spec drifted from the live system with nothing comparing the two:
`server-container.json` described a container that was never built; the Dataform
models keyed on a column real traffic never has; `schema.json` declared 27
columns the table never had. Each was invisible because the check that would
have caught it either did not exist or could not fail. `assert_stg_sessions` had
been reporting green for months over an empty result set.

**Assertions that cannot fail are the common thread**, and I wrote two of them
this session. The platform review disproved one by mutation — replacing the
entire schema-reconcile block with an `echo` left all six assertions green. Both
are now executable and both were verified by inducing the exact failure.

**`allUsers` holds `roles/run.invoker`** on the metabase Cloud Run service.
Contained by `INGRESS_TRAFFIC_INTERNAL_LOAD_BALANCER` (which is itself declared
and not under `ignore_changes`), so IAP remains the only route in — but the two
controls are independent. Recorded, not revoked; a decision for a person.

**Web Vitals race the consent bridge.** LCP, FCP and TTFB resolve before the
bridge runs on React mount, with `wait_for_update: 500` as the grace window. A
first-time visitor's Web Vitals are lost to their own consent decision. Correct
behaviour, but it skews field data toward returning visitors.

**`useLiveEvents` latches `sseEverDelivered`** on the first SSE event, so a
decliner whose exempt `consent_update` reaches sGTM can see a timeline that
shows one event and freezes. Nothing false is asserted since the routing labels
are now honest, but the latch is untouched.

**`eslint .` scans agent worktrees.** While a review agent's worktree exists
under `.claude/worktrees/`, the project lint reports its files, so "lint clean"
is unreliable at exactly the moment a review is running.

**Historical data is permanently hollow.** Payload values dropped before the
schema reconcile were discarded at write time, not stored. Raw data before
~2026-07-10 is also past the 60-day partition expiry.

**Deferred:** the RAG snapshot tables (`setup_rag.sql`) are a hand-run
`CREATE OR REPLACE` and must be re-run after Dataform rebuilds with the resolved
session key, or the AI layer stays frozen on generator-only marts.
