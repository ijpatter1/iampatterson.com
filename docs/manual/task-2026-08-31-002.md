## Context

claudish-proxy enforces the $25/day backstop as DAILY_BUDGET_USD=23 of
model spend (the remaining ~$2 covers the Cloud Run floor + headroom;
reservation-based token accounting, auto-trip to cache-only, kill
switch). GCP budgets are
MONTHLY and their alerts LAG BY HOURS — this alert is not enforcement;
it is how you find out the in-process counter was wrong.

   → Create budget.
2. Scope: project `iampatterson`, services: Vertex AI + Cloud Run
   (leave the rest unticked so site infra doesn't mask a Claudish spike).
3. Amount: $750/month (≈ $25/day expressed monthly).
4. Thresholds: 50% / 90% / 100%, email alerts to the billing admins.
   - Expected result: a saved budget named e.g. `claudish-daily-cap-proxy`.
5. If an alert ever fires mid-month at a surprising level, the runbook
   response is the kill switch (README in
   infrastructure/cloud-run/claudish-proxy/), then read the proxy's
   /health budgetUsedPct and the `budget_threshold` log events.
