## Steps

1. **Model Garden enablement (UI, do first — starts the approval clock).**
   Go to https://console.cloud.google.com/vertex-ai/publishers/anthropic/model-garden/claude-haiku-4-5?project=iampatterson
   → click **Enable** and accept the Anthropic terms.
   - Expected result: the model page shows "Enabled". Approval may take
     24–48h; if it doesn't flip immediately, continue and re-check later.
   - While there: note the retirement date the model page shows in
     **Notes** below (the research memo's floor is 2026-10-15, six weeks
     out — it decides how soon the pinned model ID needs a bump).

2. **Run the script:** `bash docs/manual/task-2026-08-31-001.sh`
   - It enables the Vertex API, reads the `anthropic-claude-haiku` quota
     metrics, and creates the `claudish-anthropic-api-key` secret shell.
   - After step 1's approval lands, run
     `bash docs/manual/task-2026-08-31-001.sh --probe`
     for the definitive end-to-end check (one 1-token call, ~$0.001).

3. **Anthropic API key (UI).** Go to https://console.anthropic.com →
   Settings → API keys → **Create key**, name it `claudish-proxy`.
   Fund the account (Billing → add credits). Fund at least the daily cap
   — the credit balance, not the proxy's $25/day cap, is the binding
   limit on this lane; $25–50 covers a bad day with headroom. Then
   re-run the script (step 2) and paste
   the key when prompted — it stores it in Secret Manager and never
   touches disk or shell history. Delete the key from your clipboard.

4. **Quota check (UI, only if the script couldn't read them).**
   https://console.cloud.google.com/iam-admin/quotas?project=iampatterson
   → filter `anthropic-claude-haiku` → record the three
   `global_online_prediction_*` values in **Notes** below.
   - Expected result: 2,500 / 2,500,000 / 250,000. Anything nonzero at
     that scale needs no increase filed — the toy peaks near 60 QPM.

### Contingency — quota stuck at 0

New-ish Vertex-Claude projects sometimes show 0 with increase requests
auto-denied (`NOT_ENOUGH_USAGE_HISTORY`). Paths, in order:
1. Wait 48h after Model Garden approval with billing active, re-request.
2. Support case: Vertex AI → Generative AI → Model access (needs a paid
   support plan).
3. The proxy's routing ladder makes the Anthropic API lane (step 3) the
   working fallback in the meantime — dev and even launch can run on it.
